# Installation de Supabase avec Bun

## Client Supabase

```bash
bun add @supabase/supabase-js
```

## Next.js (recommandé)

```bash
bun add @supabase/supabase-js @supabase/ssr
```

## CLI Supabase (dépendance de développement)

```bash
bun add -d supabase
```

## CLI Supabase (installation globale)

```bash
bun add -g supabase
```

bun run generate:supabase-types
